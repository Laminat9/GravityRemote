**GravityRemote** — это легковесный, быстрый и безопасный Telegram-бот на Python для дистанционного мониторинга и управления компьютером под управлением **Windows 10 / 11**.

Бот превращает ваш смартфон в удобный пульт дистанционного управления: просматривайте нагрузку на процессор и память, делайте скриншоты рабочего стола, управляйте запущенными окнами и звуком, открывайте нужные программы или передавайте файлы между телефоном и ПК без необходимости поднимать тяжелые RDP/TeamViewer/AnyDesk решения.

## 🚀 Быстрый старт

### 1. Регистрация бота в Telegram
1. Откройте Telegram и найдите официального бота [@BotFather](https://t.me/BotFather).
2. Отправьте команду `/newbot`.
3. Задайте имя (например: `My PC Remote`) и юзернейм бота (например: `my_pc_remote_control_bot`).
4. Скопируйте выданный токен вида: `1234567890:ABCdefGHIjklMNOpqrsTUVwxyz`.

### 2. Получение своего Telegram User ID
Для защиты ПК бот принимает команды **только** от доверенного ID владельца:
1. Откройте бота [@userinfobot](https://t.me/userinfobot) или [@myidbot](https://t.me/myidbot).
2. Нажмите **Start** и скопируйте ваш числовой ID (например: `987654321`).

### 3. Клонирование и установка зависимостей
Откройте терминал (PowerShell или CMD) и выполните:

```powershell
# 1. Клонируйте репозиторий
git clone https://github.com/your-username/GravityRemote.git
cd GravityRemote

# 2. (Рекомендуется) Создайте виртуальное окружение
python -m venv venv
.\venv\Scripts\activate

# 3. Установите зависимости
pip install -r requirements.txt
```

### 4. Настройка файла переменных окружения (.env)
Скопируйте шаблон конфигурации в `.env`:

```powershell
copy .env.example .env
```

Откройте созданный файл `.env` в любом текстовом редакторе и укажите ваши параметры:

```env
# Токен бота из @BotFather
BOT_TOKEN=1234567890:ABCdefGHIjklMNOpqrsTUVwxyz

# Ваш числовой Telegram ID
ALLOWED_USER_ID=987654321

# Папка по умолчанию для файлов, загружаемых на ПК через Telegram (опционально)
DEFAULT_DOWNLOAD_DIR=C:\Users\Username\Downloads\FromTelegram

# Прокси (раскомментируйте, если требуется доступ через локальный прокси без системного VPN)
# PROXY_URL=socks5://127.0.0.1:10808
```

> [!IMPORTANT]
> Никогда не публикуйте и не передавайте файл `.env`. Он уже добавлен в `.gitignore`.

### 5. Первый запуск
Запустите бота:

```powershell
python bot.py
```

Откройте созданного бота в Telegram и отправьте команду `/start`. Перед вами появится главное меню управления.

## 🔄 Автозапуск в фоновом режиме (24/7)

Чтобы бот работал в фоновом режиме без постоянно открытого окна терминала, настройте автозапуск одним из следующих способов:

### Способ 1: Планировщик заданий Windows (Task Scheduler) — Рекомендуется

Запуск через `pythonw.exe` (интерпретатор Python без консольного окна):

1. Нажмите `Win + R`, введите `taskschd.msc` и нажмите **Enter**.
2. В правой колонке нажмите **«Создать задачу...»** (Create Task).
3. **Вкладка «Общие» (General):**
   - Имя задачи: `GravityRemote`
   - Переключатель: **«Выполнять только при входе пользователя»** *(необходимо для создания скриншотов и управления окнами/звуком)*.
   - Отметьте чекбокс: **«Выполнить с наивысшими правами»** *(для завершения привилегированных процессов)*.
4. **Вкладка «Триггеры» (Triggers):**
   - Нажмите **«Создать...»** -> Начать задачу: **«При входе в систему»** -> **ОК**.
5. **Вкладка «Действия» (Actions):**
   - Нажмите **«Создать...»** -> Действие: **«Запуск программы»**.
   - Программа или сценарий: укажите путь к `pythonw.exe` (например: `C:\Users\Username\AppData\Local\Programs\Python\Python313\pythonw.exe` или путь к `venv\Scripts\pythonw.exe`).
   - Добавить аргументы: `bot.py`
   - Рабочая папка: полный путь к директории проекта (например: `C:\GravityRemote`).
6. **Вкладка «Параметры» (Settings):**
   - Снимите галочку: **«Останавливать задачу, выполняемую дольше...»**.
   - В пункте «Если задача уже выполняется»: выберите **«Не запускать новый экземпляр»**.
7. Нажмите **ОК**. Теперь бот будет автоматически подниматься при входе в Windows.

---

### Способ 2: Запуск в качестве службы через NSSM

Если вам требуется перезапуск бота в случае непредвиденных сбоев:

1. Скачайте **NSSM** (Non-Sucking Service Manager) с [nssm.cc](https://nssm.cc/download).
2. Распакуйте утилиту (например, в `C:\Tools\nssm\`).
3. Запустите командную строку от имени Администратора:
   ```cmd
   C:\Tools\nssm\win64\nssm.exe install GravityRemote
   ```
4. В графическом окне укажите:
   - **Path:** путь к `python.exe`
   - **Startup directory:** путь к папке проекта с `bot.py`
   - **Arguments:** `bot.py`
5. Нажмите **Install service**.
6. Запустите службу:
   ```cmd
   net start GravityRemote
   ```

## 🎮 Возможности управления и команды

### Команды бота

- `/start` — Открыть интерактивное главное меню с кнопками.
- `/status` — Быстрый снимок состояния (CPU, RAM, диски, Uptime).
- `/apps` — Мгновенный список всех запущенных приложений и окон.
- `/lock` — Заблокировать экран компьютера (`Win + L`).
- `/help` — Подробная справка по работе с ботом.
- `/cancel` — Прервать текущую операцию ввода пути или имени ярлыка.

## 📦 Настройка ярлыков приложений

Вы можете добавлять собственные программы, скрипты и ссылки двумя способами:

### Способ 1: Через диалог Telegram
1. Нажмите **🚀 ЯРЛЫКИ** -> **➕ Добавить ярлык**.
2. Введите отображаемое имя (например, `VS Code`).
3. Введите путь к исполняемому файлу (например, `C:\Program Files\Microsoft VS Code\Code.exe`).

### Способ 2: Через файл `config_apps.json`
Отредактируйте файл `config_apps.json` в корне проекта:

```json
{
  "Discord": "%LOCALAPPDATA%\\Discord\\Update.exe --processStart Discord.exe",
  "DuckDuckGo": "https://duckduckgo.com",
  "Telegram": "%APPDATA%\\Telegram Desktop\\Telegram.exe",
  "Notepad": "notepad.exe",
  "Custom Script": "C:\\Scripts\\backup.bat"
}
```

* **Веб-ссылки:** ссылки с `http://` и `https://` открываются в браузере по умолчанию.
* **Скрипты:** файлы `.bat` и `.cmd` запускаются в фоновом режиме через `cmd.exe /c`.
* **Переменные:** поддерживаются системные переменные Windows (`%LOCALAPPDATA%`, `%APPDATA%`, `%USERPROFILE%`).

## 🛡️ Безопасность и защита данных

- **Белый список (Whitelist):** Любые входящие сообщения от пользователей, чей ID не совпадает с `ALLOWED_USER_ID`, мгновенно отклоняются.
- **Подтверждение опасных действий:** Деструктивные операции (выключение, перезагрузка, спящий режим, завершение процессов, очистка корзины) требуют явного нажатия кнопки **✅ Подтвердить**.
- **Журнал аудита:** Все важные события логируются в файл `bot_actions.log` (формат: время, User ID, действие, статус).
- **Маскирование секретов:** Токены ботов, пароли и чувствительные паттерны автоматически заменяются на `***REDACTED***` перед записью в лог.

## ❓ Часто задаваемые вопросы (FAQ)

<details>
<summary><b>Бот не отвечает в Telegram</b></summary>

1. Проверьте, запущен ли скрипт: `python bot.py`.
2. Убедитесь, что в `.env` указан верный `ALLOWED_USER_ID`. Если ID отличается, бот вернет сообщение о запрете доступа и запишет инцидент в лог.
3. Проверьте интернет-соединение или доступность серверов Telegram. Если требуется прокси, настройте параметр `PROXY_URL` в `.env`.
</details>

<details>
<summary><b>Скриншот экрана получается черным или выдает ошибку</b></summary>

Если бот работает как служба без графической сессии (Session 0 Isolation), Windows не предоставляет доступ к видеопамяти. Для корректной работы захвата экрана запускайте бота под активным пользователем через **Планировщик заданий (Task Scheduler)** с параметром «Выполнять только при входе пользователя».
</details>

<details>
<summary><b>Ошибка управления звуком (pycaw / comtypes)</b></summary>

Убедитесь, что в системе установлена библиотека `pycaw` и инициализирован звуковой драйвер Windows по умолчанию. Если на ПК нет активных аудиоустройств вывода (динамики/наушники), Windows API может возвращать ошибку отсутствия устройства.
</details>
